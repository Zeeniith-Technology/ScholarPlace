# Piston Code Execution Service

This is a self-hosted Piston instance for ScholarPlace code execution.

## Deployed on Render

- **URL:** Will be provided after deployment
- **Runtime:** Docker
- **Plan:** FREE tier
- **Usage:** Unlimited code executions for all supported languages

## Supported Languages

- Python 3.10.0
- JavaScript (Node.js 18.15.0)  
- C (GCC 10.2.0)
- C++ (GCC 10.2.0)
- Java 15.0.2
- And many more!

## API Endpoint

```
POST https://your-piston-url.onrender.com/api/v2/piston/execute
```

See main ScholarPlace backend for usage examples.
